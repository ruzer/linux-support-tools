# Maestria Docker Lab

Wrapper for:

https://github.com/ruzer/maestria-anahuac-datos-docker

Commands:

```powershell
maestria-lab setup
maestria-lab start
maestria-lab status
maestria-lab urls
maestria-lab stop
```

Services:

- MySQL 8
- Adminer
- Metabase
- Apache Superset
- Jupyter Notebook/Lab
- Streamlit
- MySQL backups

Requires Docker Desktop and a Windows restart after Docker installation.
