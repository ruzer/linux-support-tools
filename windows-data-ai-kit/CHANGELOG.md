# Changelog

## 0.2.0 - 2026-06-08

- Add `START-MAESTRIA.cmd` for AI, programming, data mining, statistics, documents, and support tools.
- Add optional `InstallSupportTools` profile with diagnostics, remote support, disk utilities, bootable USB tools, sync, networking, and media tools.
- Add `pc-audit` local support command for hardware/software reports.
- Expand academic/data profile with Gephi, Power BI, pgAdmin, MongoDB Compass, DbGate, WinMerge, Bruno, Postman, DevToys, JASP, and jamovi.
- Expand macOS installer with `--maestria` and `--support` profiles.

## 0.1.0 - 2026-06-08

- First versioned Windows/macOS data and AI bootstrap kit.
- Windows menu-based installer with base, recommended, all-extras, and custom profiles.
- Windows tools for video download/transcription, file downloads, and Markdown conversion.
- Optional academic, local AI, geodata, automation, Docker, Hyperspace, and security extras.
- macOS Homebrew/Miniforge installer with matching profile concept.
