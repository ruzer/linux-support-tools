# Changelog

## 0.2.0 - 2026-06-08

- Add `START-MAESTRIA.cmd` for AI, programming, data mining, statistics, documents, and support tools.
- Add optional support-tools profile with diagnostics, remote support, disk utilities, bootable USB tools, sync, networking, and media tools.
- Add `pc-audit` local support command for hardware/software reports.
- Expand academic/data profile with BI, graph analysis, database, API, statistics GUI, and programming utilities.
- Expand macOS installer with `--maestria` and `--support` profiles.

## 0.1.0 - 2026-06-08

- Add `windows-data-ai-kit` for Windows 10/11 data, AI, R, media, and academic workstation setup.
- Add interactive Windows launcher menu plus quick launchers:
  - `START-HERE.cmd`
  - `START-RECOMMENDED.cmd`
  - `START-BASE-ONLY.cmd`
  - `START-ALL-EXTRAS.cmd`
- Add Windows media tools:
  - `vt`
  - `transcribir-video`
  - `dl`
  - `to-markdown`
- Add optional Windows profiles for academic open-source tools, local AI apps, geodata, automation, Docker, Hyperspace, and Malwarebytes.
- Add macOS bootstrapper under `windows-data-ai-kit/macOS` using Homebrew and Miniforge.
- Document recommendation to rename the repository to `lab-bootstrap-tools` when the project formally becomes multi-OS.
